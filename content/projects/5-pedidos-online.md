Metric Pulse pulls data from the APIs you already use — GitHub (commits, issues, PRs), Linear (sprint progress), and Vercel (deployment status, error rates) — and displays everything on a single configurable dashboard.

Users can drag widgets, set custom date ranges, and configure alerting thresholds. All data is cached in PostgreSQL to keep API rate limits under control.
